# 胶片工作台

打开项目，在「画布」「文档」旁选择「胶片」。

1. 从「项目视频」加入首段，或填写梗概，选择已配置的语言模型生成三个分镜草稿。目标时长用于拆分与对照。每个草稿都可修改名称和动作。
2. 选中已有视频的片段，点「末 10 帧」。点击缩略图可放大检查动作和构图。点「用这帧续拍」，将参考帧带入下一段草稿。
3. 编辑下一段动作后，选择支持单图或可选尾帧的模型。点击「生成本段」。生成成功后，上段的播放范围结束于所选帧。脚本模型可以单独续写动作，生成前可手动修订。
4. 点时间轴上任一片段查看细节。需要精确控制总时长时，可填写最后一段的结束位置并保存。每段素材就绪后，点「合成预览」，即可播放和下载一份 MP4。

续拍使用上一段选定画面的图像作为条件，后续片段由供应商独立生成。接点能延续构图和造型，动作速度与布料走势仍需逐段验看。模型时长选项来自已配置供应商。H3 首帧模式由相应供应商接入。

项目的胶片数据写入 `assets/filmstrip.json`，参考帧、视频输出和合成预览保存在项目素材目录。保存时校验文件版本，多个窗口同时编辑发生冲突时会提示重新载入。视频任务在提交前记录身份，失联后点「复查原任务」找回进度。截帧和合成使用服务器的 FFmpeg，音轨在各片段间依序拼接，无音轨的片段以静音补齐。
