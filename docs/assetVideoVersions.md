# 素材库视频超分

在素材库中选中 MP4 素材，点击「超分至 1080P」。该入口调用独立模式下已配置的 AI Nodes Platform 视频超分档位。源视频上限 100 MiB，适用于还可放大的视频。

原片可在处理期间继续预览。超分完成并通过尺寸核验后，素材仍显示为一张卡片，默认选择 1080P。卡片和播放器都可以切换到原片。下载或拖入画布使用卡片当前选中的版本。

超分输出按原片内容关联。素材重命名或移动后关联仍有效；内容相同的素材可共用同一份超分产物。网络中断时可复查原任务，任务明确失败后可手动重试。横版输出为 1920 × 1080，竖版为 1080 × 1920，具体画面适配由模型处理。
